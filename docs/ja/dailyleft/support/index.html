よくある質問

はじめかた

月の予算か一日の予算を選び、金額を一つ入れて Start（開始）を押します。アカウントもサインインもありません。

月の予算を期間の途中で始めるときは、Money Left This Month（いま残っているお金）の欄に実際に残っている金額を入れます。空けておくと予算の全額で数えます。期間の開始日、平日だけ数える、残金の扱い、カードの下4桁は More Options（その他の設定）にあり、あとから設定でも変えられます。

数える日と祝日

標準では毎日数えます。週末に使わないお金なら、設定で Count Weekdays Only（平日だけ数える）をオンにします。週末が外れ、iPhone の地域が韓国なら祝日も外れます。特定の日は、メイン画面のカレンダーで押して外します。カレンダーが閉じているときは今週だけが見えるので、ほかの週は Expand Calendar（カレンダーを開く）を押してから外します。過ぎた日は外せません。

地域が韓国の場合に使う2026年から2028年の祝日をアプリに入れてあり、次の年はアプリのアップデートで追加します。2028年は韓国天文研究院の暦データをもとに数えたもので、公式の発表が出たら合わせ直します。一覧にない年は週末だけを外します。一覧にない臨時の祝日は、カレンダーで押して外します。

期間が終わるときの残りのお金

月の予算では、期間が終わったときの残りのお金が次の期間の予算に足されます。繰り越すのは残ったお金だけで、予算より多く使った分を次の期間から引くことはありません。繰り越したお金があれば、メイン画面のバーの下の行に前の期間から繰り越した金額も出ます。新しい期間に初めてアプリを開くと、繰り越した金額が一度だけ短く表示されます。繰り越しは、最初に始めた期間か、Leftover Handling（残金の扱い）を Carries Over（繰り越し）にした期間、または Monthly Budget（月の予算）に変えた期間から始まります。そのあと予算の金額や開始日を変えても、すでに繰り越したお金は計算し直しません。一日の予算は繰り越しません。

福利厚生ポイントや支援金のように残すと消えるお金なら、設定の More Rules（詳しいルール）で Leftover Handling（残金の扱い）を Expires（消える）にします。残りのお金は繰り越さず、期間内に使い切るように知らせます。

一日の予算と期間の開始日

一日単位で使うなら、設定の予算の方式を Daily Budget（一日の予算）に変えます。数える日ごとに新しい分が生まれ、数えない日の分はありません。

予算が1日以外の日に始まるなら、設定の Period Start Day（期間の開始日）で1日から28日の中から選びます。

決済した日の一日の金額

月の予算では、今日が数える日で今日の決済があると、今日の計算を終えて、残りのお金を明日からあらためて割ります。画面には Done for today（今日の計算は終了）と表示されます。同じ日の決済をすべて取り消すと、今日をまた数えます。残高調整は決済として扱いません。

一日の金額の端数

ウォンで使う場合、メイン画面の大きな数字と状態の一行、ウィジェットに出る一日の金額は、標準で100ウォン未満を切り捨てて表示します。18,383ウォンなら18,300ウォンと出ます。月の予算なら、設定の More Rules（詳しいルール）にある Daily Amount Unit（一日の金額の単位）で、1,000、100、10、1ウォンから切り捨てる単位を選べます。選んだ単位より少ない金額はそのままで、残りの日が一日なら残りのお金をすべて表示します。合計の残高と取引の金額は切り捨てません。ウォン以外の通貨は標準では切り捨てず、同じ欄でその通貨の単位を選べます。

ショートカットのオートメーションでメッセージを記録（韓国）

最初の設定時に iPhone の地域が韓国だった場合だけ使えます。ほかの地域では Add by Hand（手動で追加）で入れます。決済の通知をテキストメッセージで受け取るなら、ショートカットのオートメーションを作っておけます。アプリを一度開いてから、ショートカットアプリでメッセージをトリガーにしたオートメーションを作り、アプリのアクション Record Payment Message（決済メッセージを記録）の Message Text（メッセージ本文）の欄にトリガーの Message（メッセージ）を入れます。作る手順は設定の Shortcuts Automation（ショートカットのオートメーション）に順に載っていて、オートメーションが一度動くとその行に Working（動作確認）と表示されます。

アプリはメッセージアプリの内容を直接読めません。オートメーションから渡された文章か、貼り付けた文章だけを読みます。どのメッセージを渡すかは、オートメーションの Contains（次を含む）の欄で決めます。승인（承認）だけを入れると、取り消しのメッセージが記録されないことがあります。取り消しのメッセージも受け取るには、この欄にカードの下4桁を入れます。

カード会社のアプリの通知と KakaoTalk の通知

カード会社のアプリの通知と KakaoTalk の通知は、iOS の制限のため自動では読めません。通知の文章をコピーして Add from Message（メッセージから追加）に貼り付けるか、Add by Hand（手動で追加）で入れます。Add from Message は地域が韓国のときだけ表示されます。

カードの下4桁（韓国）

入れると、下4桁が同じカードのメッセージだけを記録します。空けておくと、すべてのカードの決済メッセージを記録します。このとき、日付、時刻、金額を読み取れるメッセージを記録し、入金、出金、振替、ローン、請求、明細を意味する韓国語が含まれるメッセージは記録しません。拒否、失敗、不可、残高不足、限度額超過を意味する韓国語が含まれるメッセージは承認の拒否とみなし、カードの欄に関係なく記録しません。

メッセージが記録されないとき（韓国）

オートメーションの Message Text（メッセージ本文）の欄に、トリガーの Message（メッセージ）が入っているか確かめます。カードの下4桁を入れた場合は、メッセージに下4桁がそのまま書かれていないと読めません。そうでないメッセージは、カードの欄を空けるか Add by Hand（手動で追加）で入れます。

メッセージは Hana Card のメッセージの形式を基準に読み、ほかのカード会社のものは金額、日付、カードの下4桁を探して読みます。日付や時刻のないメッセージは読めず、ウォン以外の決済は記録しません。

メッセージの報告（韓国）

Add from Message（メッセージから追加）でメッセージを読めないと、結果の下に Report Message（メッセージを報告）が表示されます。押すと、原文が入ったメールの作成画面が開きます。送る前に、名前、加盟店、カード番号を消したり直したりできます。メールはご自分のメールアプリから直接送ります。

お送りいただいたメッセージは、その形式をアプリが読めるように直すことと、返信することにだけ使います。

残高が実際と違うとき

大きな数字か Adjust Balance（残高を合わせる）を押して、実際の金額を入れます。差額の分だけ Balance adjustment（残高調整）の行が一つ残り、元の取引はそのままです。調整の行と取引は、一覧でスワイプして削除します。

取り消しや返金を手で入れるときは、Add by Hand（手動で追加）で Cancellation or Refund（取り消しや返金）をオンにします。

ウィジェット

ホーム画面のウィジェットには小と中のサイズがあります。残りのお金と今日使える金額を表示し、中サイズには最近の取引3件も表示されます。

ロック画面のウィジェットは三種類です。長方形のウィジェットは残りのお金と今日使える金額、円形のウィジェットは残っている割合、一行のウィジェットは残りのお金を表示します。アプリで予算を入れる前は Not set up（未設定）か「?」と表示されます。

広告が出る場所

広告はメイン画面のいちばん下のバナー一か所に出ます。

広告の削除と購入の復元

設定の Budget and Period（予算と期間）のすぐ下にある Remove Ads（広告を削除）を一度購入すると、メイン画面の広告バナーが消え、広告の同意画面とトラッキングの確認画面も出なくなります。

機種を変えたりアプリを入れ直したりしたときは、設定の Restore Purchases（購入を復元）を押します。同じ Apple アカウントなら再び支払うことはありません。

不適切な広告の報告

不適切な広告やアプリの年齢制限に合わない広告が出たときは、出た時刻と内容を kvndh36@naver.com にお送りください。確認のうえ AdMob でブロックします。

トラッキングの許可と広告設定

初回の画面で Start（開始）を押したあと、iOS がトラッキングを許可するかを尋ねます。許可しなくてもアプリはそのまま使え、この選択は iOS の設定 > プライバシーとセキュリティ > トラッキングで変えられます。

欧州経済領域のように広告の同意が必要なところでは、同意画面がトラッキングの確認画面より先に出ます。こうしたところでは、設定の Privacy Choices（プライバシーの選択）から同意の内容を変えられます。

インターネット接続

予算の計算、記録、ウィジェットはインターネット接続なしで動きます。広告、Remove Ads の購入、購入の復元、iCloud へのバックアップ、メッセージの報告メールの送信、プライバシーポリシーを開くにはインターネット接続が必要です。

機種を変えるとき

iCloud にサインインしていれば、記録のバックアップが利用者自身の iCloud に保存されます。アプリを削除して入れ直したときや、同じ Apple アカウントの別の iPhone に入れたときは、最初の設定をする前にそのバックアップから記録を戻します。二台の記録を合わせ続ける同期ではなく、すでに記録がある端末を上書きすることはありません。

対応端末と言語

iOS 26 以降の iPhone 専用です。アプリの画面は英語と韓国語です。端末の言語リストで先に出てくるほうで表示され、どちらもなければ英語です。縦向きと横向きの画面に対応しています。金額は最初の設定時の地域の通貨で、整数だけを入れます。小数と為替換算はないため、12.50 は入れられません。メッセージの記録はウォンの決済だけを受け付けます。

不具合が起きたとき

アプリを完全に閉じてから開き直し、App Store で最新のバージョンかを確かめます。それでも続くときは、どの画面で何をしていたときに起きたかを書いてメールでお送りください。

お問い合わせ

ご質問や不具合はメールでお送りください。お使いの機種と iOS のバージョンを書き添えていただけると、確認が早く進みます。

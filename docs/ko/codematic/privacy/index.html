개인정보 처리방침

시행일 2026-10-07

요약Codematic은 개인정보를 수집하지 않습니다. 회원가입과 로그인이 없고, 넣은 코드와 건넨 기록(이용자가 적은 받는 사람 이름 포함)은 이용자 기기와 이용자 본인의 iCloud 계정에 보관됩니다. App Store Connect API 키는 등록한 기기의 키체인에만 저장되고, 키로 서명한 요청은 Apple로 직접 보냅니다.

kvndh(이하 개발자)는 Codematic 앱(이하 앱) 이용자의 개인정보를 「개인정보 보호법」에 따라 처리하며, 그 기준을 다음과 같이 알립니다.

01개인정보의 처리 목적

앱에는 회원가입과 로그인이 없고, 개발자는 이용자의 개인정보를 처리하지 않습니다. 앱은 이용자가 넣은 코드와 이용자가 적은 받는 사람 이름을 남은 수량을 세고 건넨 기록을 보여 주는 데 쓰고, 같은 Apple 계정으로 로그인한 기기끼리 묶음과 코드를 맞추는 데 씁니다. App Store Connect API 키는 이용자가 등록한 경우에만 이용자의 App Store Connect에 요청을 보내는 데 씁니다.

02처리하는 개인정보의 항목

개발자가 수집하는 개인정보 항목은 없습니다. 앱이 쓰는 자료는 아래와 같으며, 이용자 기기의 앱 저장공간에 보관됩니다. 기기가 iCloud에 로그인되어 있으면 묶음과 코드는 이용자 본인의 iCloud 계정(CloudKit 개인 데이터베이스)에도 보관됩니다. 개발자는 이 자료를 받지 않습니다.

  • 묶음(이름, 종류, 복사 방식, App Store 앱 ID, 만료일, 만든 때, 휴지통에 넣은 때, 앱에서 발급하거나 가져온 묶음이면 App Store Connect의 배치 식별자): 묶음을 나눠 보여 주고 남은 수량을 셀 때 사용
  • 코드(코드 값, 건넸는지 여부, 건넨 시각): 다음 코드를 내고 건넨 기록을 보여 줄 때 사용
  • 받는 사람 이름: 코드를 건넬 때 이용자가 직접 적는 선택 입력이며 다른 사람의 이름이나 별명일 수 있음. 건넨 기록, 건넨 뒤의 카드, 저장하는 이미지, 내보내는 CSV에 표시. 묶음, 코드와 함께 이용자 기기와 이용자 본인의 iCloud 계정에 보관
  • App Store Connect API 키(키 ID, 개인 키, 팀 키는 Issuer ID): 이용자가 등록한 경우에만 이용자의 App Store Connect에서 앱, 상품, 오퍼, 코드를 읽고 만들 때 사용. 등록한 기기의 키체인에만 저장하고 iCloud로 동기화하지 않음
  • 앱 아이콘 캐시(묶음의 App Store 앱 ID로 받은 앱 아이콘과 앱 이름): 묶음과 저장하는 이미지에 표시할 때 사용. 기기의 캐시 폴더에 두고 7일이 지나면 다시 받음

03처리 및 보유 기간

개발자가 보유하는 개인정보가 없습니다. 묶음과 코드, 받는 사람 이름은 이용자가 지울 때까지 남습니다. 묶음을 휴지통에 넣으면 30일이 지난 뒤 앱을 열 때 코드와 함께 영구히 지워지고, 휴지통에서 바로 영구 삭제할 수도 있습니다. 한 기기에서 지우면 iCloud의 사본과 같은 계정의 다른 기기에서도 지워집니다. 기기의 앱 자료는 앱을 삭제하면 함께 지워지지만, iCloud에 둔 사본은 이용자의 iCloud 계정에 남습니다. App Store Connect API 키는 이용자가 정보 화면의 'App Store Connect 키'에서 지울 때까지 그 기기의 키체인에 남습니다.

04제3자 제공

개인정보를 제3자에게 제공하지 않습니다.

05처리 위탁

개인정보 처리를 위탁하지 않습니다. 묶음과 코드의 저장과 기기 사이 동기화는 Apple의 iCloud(CloudKit)로 이루어지며, 그 자료는 이용자의 Apple 계정에 속하고 Apple의 개인정보 처리방침을 따릅니다. 개발자는 그 내용을 볼 수 없고 받지 않습니다. 묶음에 App Store 앱 ID가 있으면 앱은 그 앱의 아이콘과 이름을 Apple의 App Store 공개 정보(itunes.apple.com)와 그 응답에 적힌 아이콘 그림 주소에서 받아 옵니다. 이때 앱 ID와 지역 코드를 보내며, Apple은 일반적인 웹 요청과 마찬가지로 기기의 IP 주소를 받습니다. 쿠키와 로그인 정보는 보내지 않습니다. 공개 정보에 그 앱이 없고 App Store Connect API 키가 등록되어 있으면 아이콘과 이름을 App Store Connect에서 받습니다. App Store Connect API 키를 등록하면 앱은 그 키로 서명한 요청을 Apple의 App Store Connect API(api.appstoreconnect.apple.com)로 직접 보내 앱, 상품, 오퍼, 코드를 읽고 만듭니다. 이 요청은 개발자의 서버를 거치지 않습니다.

06파기 절차와 방법

개발자가 보유하는 개인정보가 없어 파기할 대상이 없습니다. 묶음을 휴지통에서 영구 삭제하면 그 묶음의 코드와 받는 사람 이름이 함께 지워지고, 건넨 코드를 되돌리면 그 코드에 적은 받는 사람 이름이 지워집니다. 이 기기의 앱 자료는 앱을 삭제하면 지워집니다. App Store Connect API 키는 앱을 삭제하기 전에 정보 화면의 'App Store Connect 키'에서 '키 삭제'로 지웁니다. iCloud에 둔 사본은 설정 앱의 사용자 이름 > iCloud > 저장 공간 > Codematic에서 지울 수 있습니다.

07정보주체와 법정대리인의 권리와 의무, 행사 방법

개발자가 보유한 개인정보가 없으므로 열람, 정정, 삭제를 요청할 대상이 없습니다. 궁금하신 점은 아래 메일 주소로 문의해 주시기 바랍니다.

08안전성 확보 조치

앱이 쓰는 자료는 기기의 앱 저장공간에 있습니다. 개발자의 서버는 없습니다. iCloud 저장은 이용자 본인 iCloud 계정의 개인 데이터베이스(CloudKit)를 쓰며, 앱 안에 끄는 스위치는 없고 iCloud에 로그인하지 않은 기기에서는 그 기기에만 저장합니다. App Store Connect API 키는 등록할 때 Apple에 한 번 확인한 뒤 그 기기의 키체인에만 저장하며, 기기 잠금이 풀려 있을 때만 읽고 iCloud 키체인으로 동기화하지 않습니다. 다른 기기에서는 따로 등록합니다. 파일 앱이나 AirDrop에서 앱으로 넘긴 .p8 파일의 앱 안 사본은 읽은 뒤 지웁니다. 사진은 이용자가 '이미지로 저장'을 누를 때 추가 전용 권한으로 저장만 하며, 사진 보관함을 읽지 않습니다. 코드를 건네거나 다시 복사할 때 코드나 링크를 클립보드에 넣고, 클립보드의 글은 붙여넣기 버튼을 누를 때만 가져옵니다. 기기 백업(iCloud 백업 등)을 켜 두었다면 앱 저장공간의 자료도 다른 앱의 자료처럼 백업에 들어가며, 백업은 Apple이 다룹니다.

09자동 수집 장치의 설치와 운영, 거부 방법

쿠키, 광고 식별자, 방문 분석 도구를 쓰지 않습니다.
